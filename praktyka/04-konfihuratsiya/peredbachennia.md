# Передбачення: що Python прочитає з pastky.yaml

| Ключ        | Моє передбачення: значення і тип | Показав perevir.py                 |
| ----------- | -------------------------------- | ---------------------------------- |
| svitlo      | `off`, рядок                     | `False`, логічне                   |
| pochatok    | `2026-09-28`, рядок              | `datetime.date(2026, 9, 28)`, дата |
| kod_dostupu | `010`, ціле число                | `8`, ціле число                    |
| limit       | `1000`, дробове число            | `'1e3'`, рядок                     |
| port        | `8080`, ціле число               | `8080`, ціле число                 |
| komentar    | `None`, порожнє значення         | `None`, порожнє                    |

## Спостереження

Найбільше мене здивувало значення `kod_dostupu`: запис `010` був прочитаний як число `8`, а не як рядок. Також `off` перетворився на логічне `False`, а `2026-09-28` — на дату. Щоб уникнути такого автоматичного визначення типів YAML, неоднозначні значення потрібно брати в лапки.
