# Передбачення: правила Markdown

## Передбачення 1

Два рядки без порожнього рядка між ними. Скільки рядків покаже перегляд?

Моє передбачення: я думаю, що вони покажуться як два окремі рядки.

**Показав:** два рядки відображаються як один абзац, а не як два окремі абзаци.

**Я не вгадав, бо:** у звичайному Markdown один перенос рядка всередині абзацу зазвичай не створює новий абзац.

## Передбачення 2

Які номери побачимо в списку?

Моє передбачення: я думаю, що Markdown автоматично виправить нумерацію і покаже 1, 2, 3.

**Показав:** список відображається як 1, 2, 3.

**Я вгадав, бо:** Markdown сам нумерує елементи впорядкованого списку, навіть якщо в початковому тексті всюди написано 1.

## Передбачення 3

Чи буде слово жирним?

Моє передбачення: я думаю, що слово не буде жирним, тому що між двома зірочками є пробіл.

**Показав:** слово не стало жирним.

**Я вгадав, бо:** пробіл перед закриваючими зірочками порушує правильне оформлення жирного фрагмента.

## Передбачення 4

Чи буде це таблицею?

Моє передбачення: я думаю, що це не буде таблицею, тому що немає рядка з дефісами.

**Показав:** це не відображається як таблиця.

**Я вгадав, бо:** для Markdown-таблиці потрібен рядок-роздільник із дефісами між заголовком і даними.
