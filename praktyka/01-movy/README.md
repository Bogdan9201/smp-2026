# Робота 1. Три предметні мови

Тема 1 · до **7 балів** · здати **до кінця пари**

## Умова

Знайдіть **три предметні мови у власному досвіді** й для кожної дайте
відповідь на три питання:

1. яку **задачу** вона розвʼязує і хто її кінцевий користувач;
2. що вона робить **простим**, чого без неї було б довго;
3. де її **межа** — що нею робити не варто.

3–5 речень на мову.

**Не можна брати** приклади, які були на парі. Шукайте свої: у грі,
у застосунку на телефоні, у налаштуваннях роутера, у Discord-боті.

## Що здати

Файл `movy.md` у цій теці — або повідомлення в чат заняття,
якщо репозиторій ще не створено.

## ⭐ Із зірочкою

Знайдіть предметну мову, про яку ніхто в групі не чув, і покажіть
на ній робочий приклад.

Зробили на парі — домашнього немає. Не були або не працювали —
те саме завдання стає домашнім.

1. Мова налаштувань роутера (правила перенаправлення портів / Port Forwarding)

Задача й користувач: Адміністратор мережі налаштовує правила маршрутизації трафіку, щоб зовнішній запит з інтернету потрапляв на конкретний локальний пристрій (для прикладу камеру спостереження).
Що спрощує: Замість написання складних скриптів керування, користувач оперує чіткими сутностями: протокол, зовнішній порт, IP-адреса призначення та внутрішній порт.
Де межа: Мова стає безсилою, якщо потрібно реалізувати складну логіку фільтрації за часом доби чи глибоким аналізом вмісту пакетів, для чого її синтаксису вже недостатньо.

2. Мова команд Discord-бота (моваграматика слеш-команд /play [url])

Задача й користувач: Звичайний користувач музичного бота в чаті дає наказ відтворити аудіотрек за посиланням.
Що спрощує: Дозволяє керувати складним потоком аудіоданих на віддаленому серверах за допомогою інтуїтивного короткого тексту або інтерфейсних підказок без знання API стрімінгових серверів.
Де межа: Неможливо задати складні умови по типу «грати плейлист лише тоді, коли в голосовому каналі більше трьох людей і ніхто не говорить», оскільки обмежений набір команд не підтримує розгалужену логіку.

3. Мова налаштувань мобільного застосунку (приклад - правила «Фокусування / Не турбувати» в смартфоні)

## Git — теж предметна мова

Git має три важливі питання: що змінилося, що потрапить до наступного коміту та які коміти вже були зроблені.
`status` показує поточний стан файлів;
`add` вибирає зміни для наступного коміту;
`commit` зберігає вибрані зміни в історії;

Задача й користувач: Власник телефону задає автоматичний режим тиші під час робочих годин або тренування.
Що спрощує: Перетворює абстрактне бажання «не відволікатися» на чіткий набір тригерів - часовий проміжок, геолокація або підключення до певних навушників плюс винятки для обраних контактів.
Де межа: Система не здатна розрізнити важливість дзвінка за змістом самої розмови (чи це екстрена ситуація від незнайомого номера, чи звичайна реклама), оскільки оперує лише метаданими контакту.
