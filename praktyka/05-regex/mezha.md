# Межі застосування регулярних виразів

Регулярні вирази не варто використовувати як єдиний спосіб перевірки складних дат у календарі, наприклад для визначення кількості днів у кожному місяці та високосних років. Навіть якщо вираз перевіряє формат дати, він може дозволити неіснуючу дату, наприклад 31.02.2026. Для таких перевірок краще використовувати стандартні засоби роботи з датами в мові програмування, які перевіряють календарну правильність.
