1. Де `git status` покаже `eksperyment.txt`?

Моє передбачення:
`eksperyment.txt` буде одночасно показаний як файл із підготовленими змінами та як файл із непідготовленими змінами.

2. Що покажуть git diff і git diff --staged?

Моє передбачення:
git diff покаже Рядок 3, тому що він ще не був доданийдо індексу.
git diff --staged покаже Рядок 2, тому що саме він бувдоданий до індексу.

3. Що потрапить у коміт без add?

Моє передбачення:
У коміт потрапить тільки та версія файлу, яка вже була додана до індексу. Рядок 3 до цього коміту не потрапить.
