# Передбачення: міні-мови Python

## A

Код:

```python
f"{7:03}"
```

### Моє передбачення

Я думаю, що результат буде:

```text
007
```

Причина: `03` означає ширину 3 символи та заповнення числа нулями зліва.

### Перевірка

Показав:

```text
007
```

Я вгадав, бо формат `03` задає ширину 3 символи та заповнення нулями.

---

## B

Код:

```python
f"[{'кіт':-<6}]"
```

### Моє передбачення

Я думаю, що результат буде:

```text
[кіт---]
```

Причина: рядок `кіт` має 3 символи, ширина поля становить 6, а `-<6` означає вирівнювання ліворуч із заповненням дефісами.

### Перевірка

Показав:

```text
[кіт---]
```

Я вгадав, бо рядок доповнюється трьома дефісами справа.

---

## C

Код:

```python
f"{2.5:.0f} {3.5:.0f}"
```

### Моє передбачення

Я думаю, що результат буде:

```text
2 4
```

Причина: `.0f` означає форматування числа з нульовою кількістю цифр після десяткової крапки.

### Перевірка

Показав:

```text
2 4
```

Я вгадав. Python форматує ці значення як `2` та `4`.

## D

Код:

```python
datetime(2026, 11, 9).strftime("%y/%m %A")
```

### Моє передбачення

Я думаю, що результат буде:

```text
26/11 Monday
```

Причина: `%y` дає дві останні цифри року, `%m` — номер місяця, а `%A` — повну назву дня тижня.

### Перевірка

Показав:

```text
26/11 Monday
```

Я вгадав.

## E

Код:

```python
"0123456789"[8:2:-2]
```

### Моє передбачення

Я думаю, що результат буде:

```text
864
```

Причина: зріз починається з індексу 8, рухається назад із кроком `-2` і зупиняється перед індексом 2.

### Перевірка

Показав:

```text
864
```

Я вгадав.
